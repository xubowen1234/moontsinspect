# Synthetic TS fixture provenance

synthetic.ts is a one-second, 64x64 test pattern plus a generated 440 Hz sine wave. No third-party recording or external media is included. Generated 2026-09-11 with FFmpeg 8.1 (Gyan Windows full build); fixture released under this repository's MIT license. FFmpeg binaries/source are not redistributed.

Recreate (byte identity can vary with FFmpeg version):

```sh
ffmpeg -hide_banner -loglevel error -f lavfi -i testsrc2=size=64x64:rate=10:duration=1 -f lavfi -i sine=frequency=440:sample_rate=48000:duration=1 -c:v mpeg2video -b:v 100k -c:a mp2 -b:a 64k -mpegts_service_id 7 -metadata service_name=MoonTSInspect -f mpegts synthetic.ts
ffprobe -v error -show_programs -show_streams -of json synthetic.ts
```

Independent expected inventory: program 7, PMT PID 4096, PCR PID 256, video PID 256 (stream_type 2), audio PID 257 (stream_type 3). CRC test includes an extracted PAT from these independently generated bytes.
